# 人工智能具身智能投稿推荐

<a href="https://quiettoolbox.github.io/"><img src="https://quiettoolbox.github.io/assets/quiettoolbox-avatar.jpg" width="32" height="32" alt="QuietToolbox"></a> **[← QuietToolbox 首页 / Toolbox Home](https://quiettoolbox.github.io/)**

人工智能、机器人与具身智能领域的会议和期刊投稿参考。

- 会议：CCF 等级、投稿截止日期、倒计时、历史录用率。
- 期刊：CCF 等级、中科院分区、JCR 分区。
- 支持按类型、等级、分区和名称筛选。

已过期日期按每年相同月日推算，标注“按往年推算”，并非官方公布的新一届截止日期。未单列摘要日期时明确使用全文截止。历史录用率保留年份，网友估计单独标注；无符合口径的数据则显示“没查到”。实际投稿请以官网为准。

数据来源链接保留在页面中，主要包括会议官网、CCFDDL 和 LetPub。

## 运行和更新

直接打开 `index.html` 即可使用；不需要构建或服务器依赖。修改其中的 `venues` 数据可更新条目。

本项目使用 GitHub Pages，从 `main` 分支根目录发布。

JCR 分区采用 LetPub 英文站公开展示的 Quartiles By JIF，核查于 2026-10-11；其分区区域未明确标注数据年份，因此不推定为某年度 JCR。各条目保存来源、核查日期及学科分区，页面悬停可查看学科详情。

会议录用统计于 2026-10-11 按 CCF DDL 数据仓库快照 `9b21dd00465fbe2a9d3501c77624639810cfdb02` 更新，18 个会议均有记录。默认展示最新可查年度及录用量/投稿量，可展开查看全部已收录年份及原始来源。投稿分母沿用来源口径；IROS 2026 的二手数据明确标记待核实。

已逐条核对 https://ccfddl.top/ 的当前展示：18 个会议的最新年份、录用量、投稿量和录用率均与上述快照一致。主表数值链接至该站，历史数据保留各年原始来源。

支持选择显示时区（默认 UTC+8）、设备时区及 AoE。城市时区按各截止日期自动处理夏令时；每个日期附 UTC 偏移。切换只改变显示，倒计时和排序保持同一截止时刻，选择保存在浏览器中。

页面分为会议（左）与期刊（右）两栏，各自显示适用列并提供独立搜索和 CCF 筛选；中科院筛选仅作用于期刊。窄屏自动上下排列。
